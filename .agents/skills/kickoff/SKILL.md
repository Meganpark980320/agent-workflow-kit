# 시작 (15분 안에 끝낸다)

1. `README.md`·과제 안내·제공 파일 목록을 읽는다. 제공 데이터는 `python scripts/profile_data.py <파일>`로 훑는다.
2. `docs/REQUIREMENTS.md`를 채운다.
   - 요구사항마다 `R1, R2…` 번호와 출처(README 몇 줄, 담당자 답 등)를 단다.
   - 필수 제출물(파일명·위치·형식)과 제약을 옮겨 적는다. 글자 그대로 옮긴다.
   - 확인 전 가정은 `A1…`로 따로 적는다.
3. `docs/QUESTIONS.md`에 업무 담당자에게 물을 질문 3~7개를 만든다.
   - 답에 따라 만드는 것이 달라지는 것만: 쓰는 사람과 결정, 성공 기준(숫자), 꼭 지킬 제약, 예외 처리, 필수와 선택의 경계.
   - 사용자에게 보여 주고, 담당자에게 한 번에 묻도록 제안한다. 답을 받으면 표의 '답·반영한 곳'을 채우고 요구사항·가정을 고친다.
4. `docs/PLAN.md`에 단계를 15~30분 단위로 나눈다. 단계마다 관련 R번호, 완료 조건, 검증 방법을 적는다.
   - 가장 위험한 것(모르는 기술·데이터 이상)을 앞에 둔다.
   - 필수 요구사항 먼저, 선택은 뒤에.
5. 첫 커밋: `docs: 요구사항·질문·계획 초안`.
6. 사용자에게 요약해 준다: 요구사항 수, 핵심 위험 1~2개, 첫 단계.
