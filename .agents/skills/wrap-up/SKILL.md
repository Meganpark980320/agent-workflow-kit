# 마무리

1. `python3 scripts/trace_check.py` — 통과 안 된 요구사항이나 '아직 비어 있음' 문서가 있으면 사용자에게 알리고, 남은 시간에 닫을 수 있는지 판단한다. 못 닫으면 보고서 한계에 적는다.
2. `docs/REPORT.md`: 무엇을 만들었나 / 주요 판단과 근거(표) / 어떻게 검증했나(숫자) / AI를 어떻게 썼나(맡긴 일·직접 확인·AI가 틀린 것을 잡은 사례) / 보안·윤리 / 한계와 다음 단계. 과장하지 않는다. 미검증은 미검증이라고 쓴다.
3. `docs/BRIEF.md` (**반드시** 채운다 — 사람이 후속 질문에 직접 답할 자료다): 사용자가 2분 안에 읽고 자기 말로 설명할 수 있게 — 핵심 결정 5개와 이유, 검증 숫자, 한계, 예상 질문 3개와 짧은 답. 실제 구현과 다른 내용이 없게 코드와 대조한다.
4. 필수 제출물(파일명·위치·형식)을 `docs/REQUIREMENTS.md`와 하나씩 대조한다. 실행 방법이 README에 있는지 확인한다.
5. 테스트를 한 번 더 전부 돌리고 결과를 남긴다. 마지막 커밋: `docs: 보고서·요약, 최종 점검`.
